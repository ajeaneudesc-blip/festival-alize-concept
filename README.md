# Festival Alizé (site concept)

Projet personnel de design et d'intégration. Le festival est **fictif** : artistes, dates, lieu et prix sont inventés pour la démonstration. Aucune billetterie réelle.

## Contenu
- Accueil avec compte à rebours, programme par jour (onglets), infos pratiques, simulateur de billets.
- Trois fichiers : `index.html`, `styles.css`, `script.js`. Aucun outil à installer.

## Technique
- HTML sémantique, CSS sans framework, responsive, onglets accessibles, mouvement réduit respecté.
